# 小程序

# 页面之间的跳转和数据传递？

  1. 页面跳转：可以通过 wx.navigateTo、wx.redirectTo、wx.reLaunch 和 wx.switchTab 等方法实现页面跳转，具体使用方式如下：
  • wx.navigateTo(url)：打开新页面，该新页面可以调用 wx.navigateBack 方法返回到原页面。
  • wx.redirectTo(url)：关闭当前页面，去往应用内的某个页面。
  • wx.reLaunch(url)：关闭所有页面，打开新页面。
  • wx.switchTab(url)：跳转到 tabBar 页面，并关闭其他所有非 tabBar 页面。

其中 url 参数为需要跳转的页面路径，可以是相对路径或绝对路径。相对路径需要以 / 开头，表示从应用的根目录开始计算。

  1. 数据传递：可以通过页面跳转时带上参数、使用全局变量、通过页面栈直接访问等方式实现数据传递。
  • 在页面跳转时，可以通过在 url 后面拼接参数的方式传递数据，如 wx.navigateTo({url: 'pages/detail/detail?id=123'})。在目标页面可以通过 options 参数获取到传递的参数，即 options.id。
  • 使用全局变量可以在不同页面中共享数据，但需要注意控制数据的修改和生命周期问题。
  • 通过页面栈可以访问页面之间的数据，即在目标页面中通过 getCurrentPages() 获取页面栈数组，再通过 page[index].data 获取页面的数据。

# 中如何使用 http 请求数据？

在小程序中，可以使用wx.request()方法来发起http请求获取数据。wx.request()是小程序提供的封装了 XMLHttpRequest 的API，可以发起 HTTP 请求。

以下是一个简单的例子，使用 wx.request() 方法向指定 URL 发送一个 GET 请求：

wx.request({
  url: 'https://www.example.com/someapi',
  method: 'GET',
  success: function (res) {
    console.log(res.data)
  },
  fail: function (res) {
    console.log('请求失败')
  }
})

其中，url参数为请求的API地址，method参数为请求的方法（GET/POST/PUT/DELETE等），success 方法是请求成功后的回调函数，fail 方法是请求失败的回调函数。在回调函数中可以使用res.data来获取服务器返回的数据。

另外，还可以使用 wx.downloadFile() 方法下载文件，使用 wx.uploadFile() 方法上传文件等。具体的API使用方法可以查看小程序开发文档。

# 在不同手机分辨率下的适配问题？

小程序在设计时应该按照设计规范进行设计，通常采用的方式是使用 rpx 作为单位进行布局，rpx 是一个自适应单位，可以根据不同的屏幕宽度自动适配，1rpx 可以表示为屏幕宽度的 1/750。

同时，可以使用小程序提供的 WXSS 样式语言中的 media 查询，根据不同的屏幕宽度设置不同的样式，从而实现不同分辨率下的适配。

如果还需要更加精细的适配，可以通过获取设备信息（如屏幕宽度、高度等）进行计算，然后动态设置组件的大小和位置。但是这种方式需要考虑兼容性和性能问题，建议在必要情况下使用，并且需要进行充分性能测试和优化。
