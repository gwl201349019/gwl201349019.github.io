# var、let、const区别？

在 JavaScript 中，var、let 和 const 都是用来声明变量的关键字，它们之间的区别如下：

  1. var：在函数作用域或全局作用域内声明变量，且声明的变量可以被重新赋值，可以在声明之前使用。

  2. let：在块级作用域内声明变量，且声明的变量可以被重新赋值，但不可以在声明之前使用。

  3. const：在块级作用域内声明常量，常量在定义后不能被重新赋值，但是当定义的常量是一个对象或数组时，对象和数组内部的属性或项是可以修改的。

总的来说，let 和 const 声明的变量拥有更加严格的作用域规则和赋值规则，可以避免与 var 一样的变量提升问题和不必要的变量覆盖问题。因此，在实际开发中，推荐使用let 和 const 来声明变量。

# 普通函数和箭头函数的区别?

JavaScript 中普通函数和箭头函数的主要区别在于以下几点：

  1. 语法：普通函数使用 function 关键字定义函数，而箭头函数使用箭头符号 => 定义函数。
  2. this 指向：箭头函数的 this 指向其定义时所在的上下文对象，而普通函数的 this 指向函数被调用时所在的上下文对象。在箭头函数中使用 this 关键字时，它会指向所在的作用域。而在普通函数中， this 关键字可以被重新赋值，并且它的值取决于调用该函数的方式。
  3. arguments (a g m s) 对象：箭头函数没有 arguments 对象，而普通函数有。在箭头函数中，可以使用 rest 参数语法（...args）来代替 arguments 对象。
  4. 构造函数：普通函数可以用作构造函数创建新的对象，而箭头函数不能。

总之，箭头函数在写法上更简洁，可以很好地避免 this 指向错误等问题。但是，因为它们不具备普通函数的一些特殊功能（如构造函数），所以在选择使用哪种类型的函数时，应该根据具体需求进行考虑。
