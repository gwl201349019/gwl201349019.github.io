# 毕业班面试内容整理

# 一、办学历

  1. 毕业两周之前，办理学历
  2. 两天之内，交齐信息和办理费用

# 二、制作简历

# 2.1 简历要求

  1. 简历模板最多两个人一样

  2. 简历必须公司真实

  3. 项目必须是本公司的项目

  4. 项目和项目之间的格式要一致，例如 标题、正文、行间距... 等字号要对应的统一，上下对齐

  5. 一页A4纸内容争取完整，尽量不要一个项目在两页

# 2.2 怎么寻找公司和项目

  1. 登录手机的应用商店，点击分类，选择项目
  2. 点开项目，项目的下面有开发者，那就是这个项目开发的公司
  3. 找到公司然后在 企查查 或者 天眼查 搜索该公司，然后点击 知识产权 就会找到该公司的项目
  4. 项目一定要避免有直播、聊天、游戏类内容的项目
  5. 项目一定要打开看，app，小程序类的要安装注册登录之后看里面的项目内容

# 2.3 熟悉项目

  1. 要记住哪些公司有哪些项目，哪些项目用哪些技术完成的

  2. 项目选择完成后一定要理清项目结构，尤其近期项目定位自己完成的模块和功能

  3. 近期的项目，某些功能怎么实现的，必须能够用语言表达出来，能说一两个

# 三、人事问题

# 3.1学历

  1. 民教网可查的
  2. www.cmhsi.com.cn 查询网址 点击证书查询
  3. 学校的位置在哪里
  4. 学校学的什么专业
  5. 在什么班级
  6. 班主任叫什么名字

# 3.2年龄

  1. boss上和人事聊得时候，可能会遇到年龄问题直接拒绝面试，但也不要因为个别几家，就直接不回复其他boss上的公司面试沟通和邀请。另外回答面试官身份证上年龄的时候，不要直接回答一句：04年的

  2. 可以这么说：我24岁

  3. 如果追问：因为当时计划生育，我有个姐姐或者哥哥，就晚上了几年户口。当时上大学也是一直拿着村里开的出生证明上的学。如果咱们公司需要，我也可以提供

  4. 可能会问到派出所能不能开证明，不要直接回答能或者不能

  5. 派出所证明可以这么说：这个我不太了解，但是我可以让我家人去派出所问问。但是我之前公司入职的话都是拿的村委会开的出生证明

# 四、面试回答一些难点问题技巧

  1. 遇到不会的问题不要一上来就是不会，不了解，沉默不说话

  2. 说话说什么？能够抓住关键字，然后直接说我在项目中怎么去使用的？

  3. 遇到完全不会的，也没有关键字可抓，我们就笑一笑说：这几年开发确实没有遇到过，想问咱们公司是用这个技术吗？您这边能大概和我说一下嘛？我正好和您学习学习。

  4. 遇到完全不会的，也可以说：哟（很惊讶的表情），这个问题问的太好了（边微笑边说），这个技术在项目中不经常使用，我用过，但没有系统整理过，我回去的看看，但实际要是用，问题不大，我回去再回顾回顾。

# 五、邀约面试注意事项

  1. 随时看boss上的信息，不要拒绝外派

  2. 面试时间预约：上午可以去一家远点的， 下午去两家近点的（面试时间都是可以和人事沟通的），不要一天就面一家

    • 建议面试时间：10:30,14:00,16:00
    • 比如10:30的在朝阳，14:00的在海淀，16:00的在朝阳，可以尽量把下午的两家安排的近一点。直接和面试官打电话沟通就行。（别一天就面一家，耽误时间还跑的累）

  3. 因为我们邀约面试的软件可能有多家，所以每家面试要记录清楚，哪个软件邀约，这家薪资多少一定要明白

  4. 尤其电话约的面试，一定要记录清楚面试地址和面试的时间，联系人电话，防止我们到了公司附近却找不到公司，又不知道怎么联系的尴尬场面，面试成功后也能准确的找到是哪一家

  5. 关于邀约面试的时候，问你面试时间，不要直接说哪天都可以，应该说：我目前只有哪天哪个时间段没有安排，您看这个时间方便吗？

  6. 投简历时间：在8-9点之间海投，后面随时关注消息

# 六、去公司面试注意事项

  1. 填写信息登记表注意事项

    • 个人信息：填表的时候，需要输入身份证号的那一块，比如自己是1997年的，可以直接把2005改成1997

    • 学校信息：直接写大学时间就可以，不需要写小学和高中，学历：本科，学位：学士

    • 家庭信息：不需要填写

    • 工作经历：简历上有几家写几家，工作时间写年月就可以

    • **证明人：**只写最近的公司联系人，只写姓，不用写全名，可以填写： 前端上班朋友的电话、我的、黄老师电话都可以

      王先生：18710110508

      黄女士：18811772685

  2. 到了公司如果没有联系人接你，直接去前台说：您好，我是来面试前端岗位的，我需要找谁？

  3. 没有前台人员：随便找一个人，您好：我是来面试前端的，我需要找谁？

  4. 面试过程中，人事问年龄和身份证上的年龄的时候，直接就说1997年，身份证也是，先把offer拿到手再说

  5. boss的算法是新注册人员或者一段时间没有用过的用户，会优先大量推荐公司，时间在3周以内，3周以后推送的公司就不会那么多了，所以我们要尽量在前三周拿下offer，一天至少面试2-3家。

# 七、学生找到工作后

  1. 有offer都先拿到手再说，哪怕学的再好，10000、12000都先把offer拿下，然后错开时间入职。（不要觉得自己学的好，然后拿个这么低的薪资觉得可惜）
  2. 因为咱们现在缺的就是真实的项目经验和工作经验，哪怕就先在公司干个2个月几个月都行。到时候在跳槽拿个15000、16000没有问题的
  3. 所有offer不能拒，只要发我们就要接，当然感觉不是很好，可以和公司商量推迟入职的时间，先去感觉比较好的公司先入职，感觉没问题其他家就不去了
  4. 拿到offer后第一时间发给我，然后我们约定时间办理入职的材料

# 八、工作中遇到问题解决方案

  1. 什么可以问同事
    • 项目需求
    • 公司相关：领工牌、鼠标、电脑找谁
    • 接口问题：前端代码正确，请求不到数据，直接找后端测试一下代码
    • 克隆代码需要的账号，密码，给项目地址的时候，顺嘴问一下账号和密码是多少
    • 跨域问题，直接和后端沟通，后端如果不解决，那就前端解决
  2. 什么不可以问同事
    • 功能需求实现需要的技术
    • 项目报错，先看报错原因，找不到直接复制错误消息在百度中搜索，实在没解决，可以找老师
  3. 和同事熟悉了就可以互相聊天和交流，当然也可以问问题
  4. 解决了一个问题，不要太激动，很正常的事情，不要感觉自己已经牛逼的不行了

# 九、公司的划分

  1. 外派：b公司需要开发项目，但是不想成立项目研发团队，于是就和a公司合作，让a公司招人，签合同，然后在b公司开发

  2. 外包：自己公司没有过多开发的项目，都是承接其他公司的项目，然后在自己公司开发，也可能派到项目合作公司开发

  3. 驻场：和外派一样，只不过是另一种说法

  4. 公司本部：这个就比较简单了，就是公司给自己的项目部招开发人员，只开发自己公司的项目就可以了

# 十、开发的形式

  1. 内网开发：就是公司开发的项目比较保密，例如军工、国家电网、银行项目。这个时候在公司开发的时候不能访问外网，只能是局域网可以访问，互相之间交流，手机可能也没有信号
  2. 封闭式开发：一般是短期项目，薪资给的比较高。就是招一些开发人员，例如前端、后端、测试等，找一个宾馆然后大家吃住都在宾馆，一起开发
  3. 独立开发：就是只有一个前端，所有的项目搭建，功能的实现都是你一个人去写，没有合作的人
  4. 合作开发：一般一个项目会有两个或两个以上前端人员，进行项目的开发
  5. 出差开发：一般有两种形式
    • 客户：本公司开发的项目，有其他公司使用，前期需要你去安装，调试，有问题直接在客户那边解决问题
    • 分公司: 分公司开发人员不够，项目比较紧，这个时候需要派你过去帮忙

# 3、就业学生入职案例分享

  1. 康浩强

    入职第一天，看到其他同事没有下班，加班到晚上7点，就直接提出离职了

    离职原因是：只拿着11000的薪资，感觉干着15000的活

    建议：前端这行业加班属于比较正常的现象，前期咱们需要积累项目经验工作经验，可以干个几个月再换工作

  2. 郝志国

    入职三天，公司只是让熟悉项目，也没有发ui和文档说做需求

    担心：公司是不是在考验我，我需不需要主动去跟项目经理要接口文档和需求

    建议：前期入职几天都是了解项目，自己可以拿个本子记下哪些文件(比如api接口、组件的封装等）在哪些目录，有哪些是不理解的，也可以适当的和同事沟通交流（或者先记录下来看不明白的点）
