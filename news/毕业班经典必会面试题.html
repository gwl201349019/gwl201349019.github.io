项目优化 性能优化的话比较大，咱们可以从好几个方面来讲。 （1）首先咱们可以从编码方面来讲： 编码方面就是咱们不要把所有的变量都放到data中，因为它会收集getter/setter这是最基础的，会收集对应的watcher。 v-if和v-for，不要一起使用，因为它每一次去循环，每一次都要去经历判断，避免造成大量的性能浪费，还有就是咱们可以使用v-show去复用dom。 （2）咱们再来说用户体验方面的优化： 你可以用vue-selection骨架屏的一种方式来提升用户体验，这也是我们做产品给用户的一种体验 （3）还可以从加载性能方面来讲： 比如说咱们图片，每个图片肯定要经过base64压缩的，你可以使用lazyload图片懒加载 你比如说好几百条数据，给它可以用长数据懒加载的方式去给它加载 （4）完事之后咱们可以说一下打包方面的性能加载： 打包方面就是说webpack，它其实就是一些配置项，我们可以从中去剖析这几个点，首先我们可以从生产环境去吧console.log去给它移除掉，完事在前端webpack中去给它排除打包项，比如externals，比如把咱们的element-ui,axios，router包括是咱们的vue，vuex它都可以去排除打包掉的 完事之后咱们还可以去进行一个cdn懒加载，比如把我们el-tree，el-table全部把它的js，以及它的css然后都以cdn的形式去给它加载进来。 咱们还可以对它的一些js码，html，css通通去给它进行一个压缩 完事之后咱们就是从用户体验，编码方面，打包优化方面去进行一个优化，

# 三、什么是对象的深浅拷贝

1. 对象的深浅拷贝相对于复合类型来说的，基本数据类型是不存在深浅拷贝的

  1. 就是我们在vue项目中修改el-table表格数据的时候，当我们点击修改的时候，会通过scope.row获取到这一行数据，如果直接赋值给el-form的表单对象，这时我们修改表单的数据的时候，table表格的数据也会改变，那么我们这个时候就需要对数据进行拷贝，就会解决这样的问题。

  2. 我常用的拷贝方法就是 JSON 序列化 , JSON.parse( JSON.stringify(obj) ),当然 es6 的 三点运算符，Object.assign() 、以及lodash的cloneDeep方法都可以进行对象的拷贝。

# 四、promise的理解

  1. promise 主要是解决异步编程回调地狱的一种方案，比传统的解决方案——回调函数和事件——更合理和更强大，使用promise也可以让我们的异步代码扁平化，看起来像同步代码，更加易读，便于后期代码的维护。

  2. promise是一个构造函数，使用的时候我们需要new一下，还可以进行链式语法的调用

  3. promise有两个过程，一个是从开始到失败，一个过程是从开始到成功，过程是不可逆的

  4. promise的参数是一个函数，函数中有两个参数，一个是成功需要回调的resolve，一个是失败需要回调的reject

  5. promise常用的两个方法，一个是 .then 成功的时候执行；一个是 .catch 失败的时候执行

  6. 当然除了 .then 和 .catch 方法，我们还有 .all 的方法接收多个promise，当都返回成功的时候执行 .then，否则执行 .catch

    ​ 我们在项目中经常使用promise的场景就是在项目中我们有两个数据请求，第二个请求的入参，要用到第一个请求的出参，所以我们只能等第一个的请求的数据返回之后，再发起第二次请求，这个时候就要用promise，比用传统的回调函数更好。

# 五、防抖和节流的使用场景和区别

  1. 防抖

    函数防抖，就是指触发事件后，函数在 n 秒后只能执行一次，如果在 n 秒内又触发了事件，则会重新计算函数的执行时间。

    ​ （实际上就是说：不管多么频繁触发事件，只有停留的时间大于我们间隔的时间，代码才会执行）

    简单的说，当一个函数连续触发，只执行最后一次。

    函数防抖一般用在什么情况之下呢？一般用在，连续的事件只需触发一次回调的场合。具体有：

    （1) 搜索框搜索输入。只需用户最后一次输入完，再发送请求；

    (2) 用户名、手机号、邮箱输入验证；

    (3) 浏览器窗口大小改变后，只需窗口调整完后，再执行resize事件中的代码，防止重复渲染。

  2. 节流

    节流就是限制一个函数在一段时间内只能执行一次，过了这段时间，在下一段时间又可以执行一次。

    ​ （实际上就是说：不管多么频繁触发事件，只保持自己的间隔时间，稳定的执行着）

    应用场景如：

    ​ (1) 输入框的联想，可以限定用户在输入时，只在每两秒钟响应一次联想。

    ​ (2) 表单验证。

    ​ (3) 按钮提交事件。

# 六、箭头函数和普通函数的区别

区别： 1、语法不同。 2、箭头函数是匿名函数，不能作为构造函数，不能使用new。 3、箭头函数不能绑定arguments，取而代之用rest参数...解决。 4、箭头函数没有原型属性。 5、箭头函数不绑定this，会捕获其所在的上下文的this值，作为自己的this值。 6、箭头函数无法使用 call（）或 apply（）来改变其运行的作用域 7、箭头函数不能当做Generator函数,不能使用yield关键字.

# 七、项目中的亮点

  1. 当一个文件夹下导入的文件比较多的时候，比如js或者vue文件，我们可以使用webapck提供的方法，require.context 自动导入多个文件

    ​ 例如我们使用全局状态管理vuex的模块化的时候，需要导入nodules文件加下的所有js文件，就可以采取这种方法导入modules下的所有js文件

    import Vue from 'vue'
import Vuex from 'vuex'

import getters from './getters'

/*
  require.context(directory, useSubdirectories, regExp)

  directory: 要查找的文件路径
  useSubdirectories: 是否查找子目录
  regExp: 要匹配文件的正则
*/

const modulesFiles = require.context('./modules', true, /\.js$/)

const modules = modulesFiles.keys().reduce((modules, modulePath) => {
  // set './app.js' => 'app'
  const moduleName = modulePath.replace(/^\.\/(\w*)\.\w+$/, '$1')
  const value = modulesFiles(modulePath)
  modules[moduleName] = value.default
  return modules
}, {})

Vue.use(Vuex)

export default new Vuex.Store({
  modules,
  getters
})

# 九、回流和重绘

回流和重绘主要是在页面渲染的时候才会触发。

回流：当某个元素的大小，位置改变时，就会引起回流。 （理解为渲染的结构）

重绘：某个元素的样式改变且位置不变，例如背景颜色，边框颜色，字体颜色等的改变时就会引起重绘。 （理解为画图的时候染色）

所以：回流必将引起重绘，而重绘不一定会引起回流

减少回流和重绘的方法：

  1. 尽量减少DOM的操作，例如创建一个列表，我们先将列表的内容进行循环拼接为字符串，然后将字符串赋值给ul，不要大量创建li，然后依次插入到ul中。
  2. 修改样式的时候尽量使用 class 修改大量样式操作，不要一个一个修改样式。
  3. 某个元素使用大量动画的时候，我们应该将该元素定位脱离文档流，来避免父元素和子元素的大量的回流
