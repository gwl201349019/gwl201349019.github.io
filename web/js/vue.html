# 组件传值

  • 父组件在引用子组件时，通过属性绑定（v-bind:）的形式，把属性传递到子组件内部

    1. 父组件传值
        <template>
        <div class="home">
            <img alt="Vue logo" src="../assets/logo.png">
            <!-- 通过绑定属性，传值 -->
            <HelloWorld msg="Welcome to Your Vue.js App"  :data1="data1" />
        </div>
    </template>

    <script>
        import HelloWorld from '@/components/HelloWorld.vue'
        export default {
            name: 'Home',
            data () {
                return {
                data1: '父组件数据data1',
                };
            },
            components: {
                HelloWorld
            }
        }
    </script>

  • 父组件向子组件传递方法，使用事件绑定机制 v-on，自定义一个事件属性，传递给子组件

    1. 父组件传值
        <template>
        <div>
            <h1>父组件</h1>
            <!-- @show是子组件触发的方法 -->
            <router-view @show="showFather"></router-view>
        </div>
    </template>
    
    <script>
        export default {
            methods: {
                showFather (a, b) {
                console.log('触发了父组件的方法' + '======' + a + '======' + b);
                }
            }
        }
    </script>

            <Button type="primary" @click="sonClick">触发父组件方法</Button>
        </div>
    </template>
    
    <script>
        export default {
            methods: {
                sonClick () {
                    this.$emit('show', 111, 222);
                }
