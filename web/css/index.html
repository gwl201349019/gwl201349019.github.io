# 文字换行

word-break: break-all; 会在单词内部断开，即使这样可能会产生一些奇怪的断字情况，比如一个单词的一部分出现在一行的末尾，另一部分出现在下一行的开头。这个属性通常用于亚洲语言，如中文、日语和韩语等，因为这些语言中没有空格或其他分隔符来分隔单词。

p {
  word-break: break-all;
}

word-wrap: break-word; 则会在单词边界处断开，以确保单词不会被截断。这个属性通常用于英文和其他使用空格或其他分隔符来分隔单词的语言。

p {
  word-wrap: break-word;
}
